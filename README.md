# 自炊献立の栄養価シミュレーター

meal-nutrition-simulator

## アプリ概要

Next.jsとSupabaseを用いた、自炊献立の栄養価をシミュレーションできるアプリです。

日付ごとに朝食・昼食・おやつ・夕食の料理名と、使用食材・使用量（g）を入力すると、
エネルギー・たんぱく質・脂質・炭水化物・食物繊維・食塩相当量を自動で計算します。

## 機能一覧

- 食材一覧取得
  - 登録済みの食材を名前順で取得
  - MVPでは約30品目から開始
- 献立のCRUD機能
  - 日付ごとに献立を作成
  - 保存した献立を一覧・詳細表示
  - 献立を更新
  - 献立を削除
  - 保存した献立は日付が新しい順に表示
- 食事・料理の登録
  - 朝食・昼食・おやつ・夕食の食事区分ごとに料理を登録
  - 料理ごとに複数の食材と使用量（g）を登録
- 献立詳細表示
  - 食事区分ごとの料理・食材・使用量を表示
  - 献立全体の栄養価を表示
- 栄養価計算（本アプリのメイン機能）
  - 各食材について「100gあたりの栄養価 × 使用量（g） ÷ 100」で栄養価を計算
  - 各食材の計算結果を合計し、献立全体の栄養価を算出
  - エネルギー・たんぱく質・脂質・炭水化物・食物繊維・食塩相当量を表示
