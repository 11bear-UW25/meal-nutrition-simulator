# 自炊献立の栄養価シミュレーター

meal-nutrition-simulator

## アプリ概要

Next.jsとSupabaseを用いた、自炊献立の栄養価をシミュレーションできるアプリです。

日付ごとに朝食・昼食・おやつ・夕食の料理名と使用食材の（g）を入力すると、
エネルギー・たんぱく質・脂質・炭水化物・食物繊維・食塩相当量を自動で計算します。

## 機能一覧

- 食材一覧取得
  - 登録済みの食材を名前順で取得（約30品目から開始）
- 献立のCRUD機能（作成・一覧／詳細表示・更新・削除）
  - 日付ごとに献立を管理
  - 朝食・昼食・おやつ・夕食の食事区分ごとに料理を登録
- 料理・食材の追加と削除
  - 料理に食材と使用量（g）を複数登録
- 栄養価計算（本アプリのメイン機能）
  - 食材の栄養価（100gあたり）× 使用量 ÷ 100を合計し、献立全体の栄養価を算出
- 献立一覧取得
  - 保存した献立を日付が新しい順に表示
- 献立詳細取得
  - 食事区分ごとの料理・食材と、献立全体の栄養価を表示
